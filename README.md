### 🚀 Who I Am

I am a **Full-Stack Engineer** from Egypt, studying at **Sphinx University**. I build for the web with **TypeScript**, **Next.js**, **React**, and **Python** — turning classroom ideas into products people can actually click, use, and ship.

- 🧩 **Product-minded:** I care about the full path — interface, logic, and the story the user feels.
- ⚡ **Stack I reach for:** Next.js, React, Tailwind, and TypeScript on the front; Python when the problem wants a sharp backend.
- 🎓 **Campus to production:** What I learn at Sphinx, I try to prove in a repo — not only in a notebook.
- 🎯 **Currently building:** **SphinxStack** — my personal full-stack lab. First public drop coming soon.
